# Cult Tycoon — Gameplay Design Reference

> Compiled from Honey, I Joined a Cult wiki, reviews, and guides.
> Source: honey-i-joined-a-cult.fandom.com, TechRaptor, Indie Game Culture, BoilingSteam, Player2, TheSixthAxis, TheGamer

## 1. Core Game Loop

1. **Build** your compound (rooms, facilities, decor)
2. **Recruit** followers → convert to cultists (employees)
3. **Assign** cultists to jobs in rooms (staffing/scheduling)
4. **Generate resources** (money, faith, influence, research, PR)
5. **Research** new rooms/objects/upgrades via tech tree
6. **Manage heat** (protests, police raids) via missions & propaganda
7. **Expand** cult → more followers → more rooms → repeat
8. **Progress** toward an ending goal (3 ideology paths at mid-game)

## 2. Resources (Economy)

| Resource | Source | Use |
|----------|--------|-----|
| **Money** | Followers spending on treatments/hoaxes | Build rooms, buy objects, decor |
| **Faith** | Daily leader sermon (19:00), missions | Pay cultist "wages", research costs |
| **Influence** | Various activities | Research, trait removal, mood boosts |
| **Research Points** | Cultists working in Research Office | Unlock tech tree nodes |
| **PR** | Missions, propaganda | Attracts higher-quality followers |
| **Heat** | Generated by dismissing followers, aggressive activities | Triggers protests → police raids if too high |
| **Prestige** | Room decor, ornaments | Cultist satisfaction based on level vs room prestige |

## 3. Cultist Stats (Needs System)

Six core stats that decay over time and must be maintained:

| Stat | Restored By | Effect if Low |
|------|-------------|---------------|
| **Health** | Food, hygiene, sleep | Cultist gets sick, may die |
| **Mood** | Overall happiness from needs being met + positive traits | Mood breaks → destructive behavior, leaves cult |
| **Hunger** | Canteen/kitchen food | Starvation, health damage |
| **Energy** | Sleep in assigned bed | Collapses, stops working |
| **Fun** | Recreation room (games, vinyl, board games) | Boredom → massive mood penalty (inevitable over time) |
| **Bladder** | Toilets (bucket → porcelain upgrades) | Accidents, hygiene drop, mood penalty |
| **Hygiene** | Showers (partitioned for privacy preferences) | Grimy status, health issues, mood penalty |
| **Prestige** | Room decor level vs cultist's expected level | Mood penalty if room too low, boost if higher |

## 4. Cultist Quality Tiers

```
very poor < poor < average < good < very good < incredible
```

- Higher tier = more skill points, higher level cap, costs more Faith to recruit
- PR level determines quality of incoming followers
- Early game: mostly "very poor" cultists (level cap 3), expendable
- Mid game: "poor" to "average" cultists (level cap 5-7)
- Late game: "good" to "incredible" cultists with positive traits

## 5. Cultist Traits & Quirks

- **Personal issues**: Bed preferences, shower privacy needs, toilet preferences
- **Job issues**: Skills they're good/bad at, rooms they won't work in
- **Positive traits**: Skill bonuses (assign to matching rooms)
- **Negative traits**: Skill penalties (exclude from those rooms)
- **Quirks**: Unique behaviors that affect mood or job performance
- Traits can be removed via Ministry of Alteration (200 Influence, or 150 with research)

## 6. Skill Groups

Cultists have skills in categories used for job assignment and mission success:

- **Maintenance** — fixing broken objects, cleaning (speed-dependent)
- **Research** — generating research points (can work at night)
- **Cooking** — food preparation in kitchen
- **Cleaning** — hygiene maintenance
- **Recruitment** — converting followers to cultists
- **Missions** — external mission success rate

## 7. Rooms (Building System)

### Early Game Rooms
- **Lobby** — greeting/recruitment of new followers
- **Research Office** — generates research points
- **Temple** — sermons, faith generation
- **Meditation Studio** — follower treatment, early income
- **Canteen** — food service (vending machines initially)
- **Bedroom** — sleep (assigned beds per cultist)
- **Bathroom** — toilets & showers (starts with buckets)
- **Maintenance Room** — tool storage for repairs

### Mid Game Rooms (Research-locked)
- **Kitchen** — proper cooking (vs vending machine food)
- **Recreation Room** — restores Fun stat (games, vinyl, board games)
- **Ministry of Truth** — propaganda generation (reduces heat)
- **Distillery** — night-time income generation
- **Free Love Room** (Peace & Love theme)
- **Special Incense Lounge** (Peace & Love theme)

### Late Game Rooms (Ideology-specific)
Three paths unlock different rooms:

**Eldritch Horror Path:**
- Bottomless Pit (sacrifice followers for money)
- Seance Center
- Soul Signing Room
- Maggot Pool
- Discombobulation Machine

**1960s Counter-Culture (Peace & Love) Path:**
- Free Love Room
- Experimental Arboretum
- Maypole Dancing Room
- Special Incense Lounge

**Futuristic Absurdity Path:**
- Robot Conversion Room
- Cybernetic Enhancement Chamber
- Soul-Strengthening Electrocution Beds

## 8. Tech Tree (Research)

- **Civilization-style** branching tech tree
- No benefit to focusing one branch — cross-dependencies between branches
- Some techs improve compound life (better toilets, kitchens)
- Others improve exploitation (more income from followers)
- **Divine Inspiration** unlock: lets leader choose ideology/path of salvation
- Each playthrough gets a **unique tech tree** with different rooms and items
- Research costs: research points + influence + faith

### Tech Tree Branches (inferred):
1. **Living Conditions** — better beds, toilets, showers, kitchen upgrades
2. **Exploitation** — new treatment rooms, income generation
3. **Cult Management** — larger follower caps, better recruitment, heat reduction
4. **Divine/Leader** — leader abilities, ideology path, endgame unlocks
5. **Security/PR** — propaganda, mission effectiveness, heat management

## 9. Scheduling & Job Assignment

- **3 shifts**: Morning, Afternoon, Night
- Cultists assigned to shifts to maintain 24/7 coverage
- Some jobs (Research, Maintenance) can run at night
- Distillery only operates at night
- **Priorities tab** — assign cultists to specific rooms
- **Schedule tab** — set sleep/work hours per cultist
- Stagger shifts to keep resources flowing

## 10. Missions System

- Send cultists outside compound on missions
- Mission success based on cultist skill levels
- **Mission Events** — random encounters during missions (dialog choices)
  - Can gain/lose money, PR, influence, items
  - Some choices require minimum skill levels
- Mission types:
  - **Heat reduction** — lower heat stat
  - **PR generation** — increase follower quality
  - **Object acquisition** — get decor/ornaments (generates heat)
  - **Resource gathering** — money, influence

## 11. Heat & Threat System

- **Heat** accumulates from:
  - Dismissing followers/cultists
  - Object acquisition missions
  - Aggressive exploitation activities
- **Consequences of high heat:**
  - **Protesters** — appear outside compound (send cultists to talk them down)
  - **Police raids** — arrest cultists, confiscate items (game-ending if severe)
- **Heat management:**
  - Heat reduction missions
  - Propaganda generation (Ministry of Truth)
  - Keep heat below 300 to avoid raids

## 12. Leader (Cult Leader) Mechanics

- Mostly idle: eats, sleeps, gives sermons
- **Daily sermon** at 19:00 → generates Faith
- **Divine Inspiration** unlock → choose ideology/path
- **Leader charm** — boost cultist mood (costs Influence)
- **Leader demands** — quests/statuses that must be fulfilled
- Leader has own stats that need maintaining

## 13. Follower → Cultist Pipeline

1. **Followers** visit compound, spend money on treatments
2. Over time, followers become recruitable
3. Convert followers to **cultists** (employees) for Faith cost
4. Follower cap and cultist cap (both expandable via research)
5. Dismissing followers/cultists generates Heat
6. Higher PR → better quality followers → better potential cultists

## 14. Prestige System

- Every room has a **Prestige Level** based on decor items
- Cultists expect prestige matching their level
- Room too low → mood penalty
- Room higher → mood boost
- **Ornaments** — best prestige boosters (from missions or Counterfeit Goods Dept)
- Decor items: rugs, plants, lights, paintings, etc.

## 15. Random Events

- Newspaper-style announcements
- Temporary effects (duration-based)
- Examples: "Garys run naked", "mouth cuts from bathroom", diseases
- Theme Hospital-style diseases (sudden baldness, bladder size reduction)
- Add humor and unpredictability

## 16. Endgame & Endings

Three ideology paths (chosen at mid-game via Divine Inspiration):

1. **Eldritch Horror** — summon Cthulhu, destroy the world
2. **Peace & Love** — achieve world peace (hippie utopia)
3. **Futuristic** — convert followers to robots, technological singularity

Each path has:
- Unique tech tree branches
- Unique rooms and objects
- Unique endgame artifacts (expensive, requires grinding)
- Different ending cutscenes

**Win condition**: Complete the ideology-specific tech tree and build the final artifacts.

## 17. Key Differences for Cult Tycoon (Our Game)

Based on the above, here's what we should adapt vs. innovate:

### Keep Similar (Proven Mechanics):
- ✅ Needs system (hunger, energy, fun, hygiene, bladder, mood)
- ✅ Room-based building system
- ✅ Tech tree research
- ✅ Follower → Cultist pipeline
- ✅ Heat/threat system
- ✅ Job assignment & scheduling
- ✅ Prestige/decor system
- ✅ Resource economy (money, faith, influence)

### Improve Upon HIJAC:
- 🔄 **3D isometric** vs their 2D top-down (already have this)
- 🔄 **Fog of war** exploration (already implemented — they don't have this)
- 🔄 **Wandering AI** (already have basic version)
- 🔄 Better UI (learn from HIJAC's UI complaints — dropdown bugs, menu flipping)
- 🔄 Better late-game pacing (HIJAC's biggest complaint was grind)
- 🔄 **Save slots** with metadata (HIJAC had single save)

### Innovate (Our Unique Selling Points):
- ⭐ **Globe-size map** with fog of war (exploration + expansion)
- ⭐ **Ritual system** with particle effects (already started)
- ⭐ **Day/night cycle** with visual atmosphere (already implemented)
- ⭐ **Audio system** with synthesized sounds (already implemented)
- ⭐ **Synty 3D asset packs** (vs their minimalist 2D sprites)

### MVP Priority Features (for Steam release):
1. Core needs system (hunger, energy, mood minimum)
2. 5-6 basic rooms (lobby, temple, kitchen, bedroom, bathroom, research)
3. Basic tech tree (10-15 nodes)
4. Follower recruitment pipeline
5. Heat system (protests, basic threat)
6. Resource economy (money, faith)
7. Save/load system
8. Win/lose conditions
9. Tutorial/tooltip system
10. Settings menu (audio, graphics, controls)

## 18. Room Data Model (for implementation)

```typescript
interface RoomType {
  id: string;
  name: string;
  category: 'basic' | 'living' | 'exploitation' | 'research' | 'security' | 'ideology';
  size: { minW: number; minH: number };
  cost: { money: number; faith?: number; influence?: number };
  researchRequired?: string; // tech node id
  prestige: number; // base prestige
  jobs: JobType[]; // what jobs cultists can do here
  needsProvided: NeedType[]; // what stats this room restores
  unlockLevel: number; // tech tree position
}

interface RoomInstance {
  id: string;
  type: string;
  position: { x: number; y: number };
  size: { w: number; h: number };
  tiles: TileCoord[];
  door: { x: number; y: number };
  objects: PlacedObject[];
  prestigeLevel: number;
  assignedCultists: string[];
}
```

## 19. Cultist Data Model (for implementation)

```typescript
interface Cultist {
  id: string;
  name: string;
  tier: 'very_poor' | 'poor' | 'average' | 'good' | 'very_good' | 'incredible';
  level: number;
  maxLevel: number; // based on tier
  skills: {
    maintenance: number;
    research: number;
    cooking: number;
    cleaning: number;
    recruitment: number;
    missions: number;
  };
  needs: {
    health: number; // 0-100
    mood: number;   // 0-100
    hunger: number; // 0-100
    energy: number; // 0-100
    fun: number;    // 0-100
    bladder: number; // 0-100
    hygiene: number; // 0-100
  };
  traits: Trait[];
  quirks: Quirk[];
  assignedBed?: string;
  assignedRoom?: string;
  shift: 'morning' | 'afternoon' | 'night';
  status: 'idle' | 'working' | 'sleeping' | 'eating' | 'break' | 'mission' | 'leaving';
}
```
