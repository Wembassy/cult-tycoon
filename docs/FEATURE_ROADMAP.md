# Cult Tycoon — Feature Roadmap

## Game Concept

**Cult Tycoon** is a cult management/tycoon game that combines the base-building and management depth of *Prison Architect* with the ritual/combat loop of *Cult of the Lamb*, wrapped in the satirical charm of *Honey, I Joined a Cult*. You build and manage a cult compound, recruit and care for followers, conduct rituals, research forbidden knowledge, and crusade against rival cults — all presented in an isometric, flat-shaded 3D aesthetic inspired by Prison Architect.

## Core Pillars

1. **Build** — Design and manage your cult compound with modular rooms, outdoor areas, and defensive structures
2. **Manage** — Care for followers' needs (food, faith, fun, health, sanity), assign jobs, train skills
3. **Ritualize** — Conduct rituals to gain power, convert recruits, and appease your Dark Patron
4. **Crusade** — Roguelike expeditions to gather resources, convert heretics, and defeat rival cults
5. **Progress** — Tech tree from humble tent meetings to dark cathedral with automated cult operations

## Phase 1: Foundation (MVP Vertical Slice)

### 1.1 Engine Core
- Three.js scene setup with isometric camera
- Tile-based world system (32x32 grid minimum)
- Entity Component System (ECS) architecture
- Input handling (mouse picking, drag selection, camera pan/zoom)
- Basic UI framework (HTML overlay on canvas)
- Game loop with fixed timestep simulation + variable render
- Save/load system (localStorage + JSON)

### 1.2 World & Building
- Terrain generation (flat grid with biomes)
- Room placement system (drag-to-place walls, floors, doors)
- Object placement (furniture, decorations, workstations)
- Room type recognition (enclosed area → designated room)
- Utility system (power/faith as resource network)

### 1.3 Followers
- Follower entities with needs system (hunger, faith, fun, health, sanity)
- Pathfinding (A* on tile grid)
- Job assignment system (priority-based task queue)
- Follower AI state machine (idle, working, eating, praying, sleeping, ritual)
- Follower appearance (customizable colors, simple 3D models)

### 1.4 Cult Management
- Cult stats: Faith, Funds, Following, Fear
- Leader character with demands/moods
- Recruitment system (convert visitors → followers → cultists)
- Basic scheduling (work/pray/eat/sleep blocks)
- Follower leveling (novice → adept → priest)

### 1.5 Basic UI
- Top bar: resources (Faith, Funds, Food, Materials, Followers)
- Bottom panel: build mode tabs (Rooms, Objects, Rituals, Crusade)
- Follower inspection panel (click follower → see stats/needs)
- Event log / notification system
- Time controls (pause, 1x, 2x, 3x speed)

## Phase 2: Depth & Combat

### 2.1 Ritual System
- Ritual circle placement
- Ritual types: Sermon (faith boost), Sacrifice (power gain), Conversion (recruit), Blessing (buff), Summon (call entity)
- Ritual mini-game (timing/click sequence)
- Ritual consequences (follower mood, Dark Patron favor)

### 2.2 Crusade / Roguelike Combat
- Expedition map with nodes (combat, event, treasure, boss)
- Real-time combat with abilities (dodge, attack, special)
- Weapon system (artifacts unlock new combat moves)
- Permadeath on crusade (lose followers permanently)
- Boss fights against rival cult leaders

### 2.3 Tech Tree
- Research points generated by studying tomes
- Tech branches: Buildings, Rituals, Combat, Automation, Dark Arts
- Unlock: new rooms, objects, ritual types, follower abilities
- Era progression (Tent Meeting → Church → Temple → Cathedral → Dark Sanctum)

### 2.4 Follower Depth
- Follower traits (insomniac, zealous, doubter, charismatic, lazy, scholar)
- Follower relationships (friendship, rivalry, romance, offspring)
- Follower quests (personal requests that boost loyalty)
- Follower outfits/customization
- Disciple system (elite followers with special abilities)

### 2.5 Dark Patron System
- Choose your Dark Patron at game start (3-4 options, each with unique bonuses/demands)
- Patron demands quests (sacrifice X, build Y, convert Z)
- Patron favor meter (high favor = blessings, low favor = curses)
- Patron-specific ritual unlock tree

## Aesthetic Direction

**Visual Style:** Prison Architect-inspired isometric view, but with 3D models instead of 2D sprites. Flat-shaded low-poly models with bold outlines. Dark, slightly desaturated color palette with accent colors for ritual/faith elements (glowing teal, gold, blood red).

**Camera:** Isometric perspective with zoom (close-up for detail, far for overview) and rotation (4 directional snaps).

**Scale:** Tiles are 1x1 world units. Buildings occupy 1-4 tiles. Followers are ~0.8 units tall. Camera at ~45° pitch, ~60° FOV.

**UI Style:** Clean, dark-themed UI panels with gold/teal accents. Minimal HUD. Diegetic elements where possible (physical notice boards, ritual circles).
